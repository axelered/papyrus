# 📄 Papyrus

Axelered Papyrus is your single point stop for Agentic document processing.


## 🧑🏼‍💻 Development

```shell
uv run fastapi dev --entrypoint server:app --reload
```

Or run development environment with Dekit

```shell
dekit reload --yes
dekit up
```

Format and Lint

```shell
ruff format
ruff check --fix
```
